🐍 Katas de Python

📖 Descripción del Proyecto:
Este proyecto reúne una serie de katas y ejercicios prácticos de Python enfocados en reforzar la lógica de programación, la resolución de problemas y las buenas prácticas de desarrollo. A lo largo del proyecto se abordan más de 40 ejercicios que abarcan desde conceptos fundamentales hasta el desarrollo de programación orientada a objetos y estructuras de datos.

🛠️ Tecnologías y Herramientas:
- Python
- Jupyter Notebook
- VS Code

🚀 Pasos Seguidos durante el Proyecto: 

- Fundamentos y Programación Funcional: Trabajo con herramientas funcionales como reduce() y funciones lambda para realizar operaciones matemáticas, concatenación de cadenas e interacciones sobre iterables.
- Manipulación de Cadenas y Datos: Implementación de algoritmos para formateo de texto, enmascaramiento de información sensible, detección de anagramas y recuento/procesamiento flexible de palabras.
- Estructuras de Datos y Validación: Uso eficiente de conjuntos (set) para la detección de elementos duplicados, diccionarios para mapeos de información y control de excepciones mediante raise ValueError e try/except.
- Programación Orientada a Objetos: Diseño e implementación de clases avanzadas (Arbol, UsuarioBanco) gestionando estado, métodos de instancia y validación de reglas de negocio (saldos, operaciones permitidas).
- Control de Flujo y Lógica de Negocio: Resolución de problemas prácticos basados en condicionales complejas (categorización horaria, rangos de calificaciones numéricas a texto, cálculo de áreas geométricas y simulación de carritos con cupones de descuento).
